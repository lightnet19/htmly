HTMLy System Static Resources (v3.2.0)
========================================

Directory Structure & Assets:
- /css: Contains stylesheets including Admin LTE, FontAwesome, typography, and `admin-2026.css` (HSL Design System & Glassmorphism).
- /js: Contains scripts for admin interactions, auto-saving drafts, media uploader, and `command-palette.js` (Ctrl+K Quick Actions).
- /fonts & /webfonts: Typography and icon font bundles.
- /images: System default UI icons and branding assets.
